# Thailand Tourism Demand

Сайт + Telegram-канал со сводкой спроса на туризм по шести направлениям Таиланда.
Всё обновляется автоматически. Руками вписывать ничего не нужно.

```
Ежедневно 08:00 (Бангкок)        Понедельник 09:00 (Бангкок)
  build_data.py                    build_data.py
       ↓                                ↓
   data.json  →  сайт             make_chart.py  →  chart.png
                                        ↓
                                  write_post.py  →  пост (Claude + веб-поиск)
                                        ↓
                                  send_telegram.py  →  канал
```

**Ежедневно** пересобираются данные, сайт всегда свежий, сообщений нет.
**Раз в неделю** выходит развёрнутый пост с графиком.

## Что подтягивается само

| Данные | Источник | Ключ |
|---|---|---|
| Погода, 8 дней, 6 точек | Open-Meteo | не нужен |
| Курсы валют | ExchangeRate-API | не нужен |
| Праздники Таиланда | Google Calendar (iCal) | не нужен |
| Праздники стран-доноров | Google Calendar — CN, RU, IN, MY, KR, GB, DE, AU | не нужен |
| Топливо, маршруты, приезды, события | **веб-поиск внутри модели** | нужен |

Праздники Таиланда — самый важный календарь, и `date.nager.at` его **не покрывает**
(отдаёт пустой ответ для TH, IN, MY). Поэтому используются публичные iCal-фиды Google.

## Как пишется пост

`write_post.py` даёт Claude Opus 5 посчитанные показатели и просит **самостоятельно
найти в вебе**, что происходит сейчас: цена авиатоплива, сокращение маршрутов,
статистика приездов, курс бата, события. Модель пишет связный пост, а не
перечисление цифр.

Именно это убирает ручной рыночный контекст. Раньше его надо было обновлять
помесячно — теперь он собирается заново каждую неделю.

Если модель недоступна или ключ не задан, `send_telegram.py` сам соберёт короткую
сводку из `data.json`. Неделя не пройдёт в тишине.

## Что автоматизировать нельзя

- **Загрузка отелей** — открытого API нет ни у кого. Только отчёты ассоциаций.
- **Точная статистика приездов** — публикуется пресс-релизами. Модель найдёт её
  в новостях, но с задержкой и без гарантии свежести.

## Настройка — один раз

### 1. Секреты

**Settings → Secrets and variables → Actions → Secrets:**

| Секрет | Где взять | Обязателен |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` | да |
| `TELEGRAM_CHAT_ID` | см. ниже | да |
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com) | для развёрнутого поста |

Без `ANTHROPIC_API_KEY` всё работает, но вместо разбора приходит короткая сводка.

### 2. Chat ID

**Себе лично:** написать [@userinfobot](https://t.me/userinfobot), взять `Id`.
Обязательно нажать **Start** у своего бота — иначе он не сможет вам написать.

**В канал:** добавить бота администратором канала с правом публикации, затем взять
id канала — он отрицательный, вида `-1001234567890`. Проще всего переслать любое
сообщение из канала боту [@userinfobot](https://t.me/userinfobot).

### 3. Сайт

**Settings → Pages → Source: Deploy from a branch → `main` / `root`.**

### 4. Проверка

**Actions → Weekly briefing → Run workflow.** Первый выпуск можно не ждать до
понедельника.

| `daily.yml` | `0 1 * * *` | ежедневно 08:00 |

## Локальный запуск

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_data.py
.venv/bin/python scripts/make_chart.py
```

Посмотреть, что уйдёт в Telegram, ничего не отправляя:

```bash
DRY_RUN=1 TELEGRAM_BOT_TOKEN=x TELEGRAM_CHAT_ID=x python3 scripts/send_telegram.py
```

Сборщик данных и отправка зависимостей не требуют — только стандартная
библиотека. `matplotlib` нужен для графика, `anthropic` — для поста.

## Как считается индекс спроса

```
score = base × (1 − rain_penalty × weather_sensitivity)
        + события + праздник Таиланда + праздники за рубежом
```

`base` — структурное положение направления, `weather_sensitivity` — пляжные
курорты ~0.45, Бангкок 0.15. Это ориентир, а не измерение.

## Оформление графика

Малые кратные: по панели на регион, поэтому **цвет не несёт идентичность** —
её несёт заголовок панели. Линия одного акцентного цвета; цветом отмечено
только сегодняшнее значение, и всегда рядом со словесной подписью уровня,
никогда цветом в одиночку. Все цвета данных проверены на контраст ≥ 3:1
к белому фону.

## events.json

Необязательный календарь для того, что не приходит из iCal-фидов: фестивали и
заходы круизных лайнеров.

```json
{"from":"2026-07-30","to":"2026-08-02","scope":"pattaya","boost":18,
 "en":"Fireworks Festival","ru":"Фестиваль фейерверков"}
```

Расписание круизов в Лаем Чабанг известно на год вперёд с точным числом
пассажиров — лучший источник для пиковых дней.

## Файлы

```
index.html                        сайт, читает data.json
data.json                         пересобирается ежедневно
events.json                       ручной календарь событий (необязательный)
scripts/build_data.py             сборщик данных
scripts/make_chart.py             график для поста
scripts/write_post.py             текст поста (Claude + веб-поиск)
scripts/send_telegram.py          публикация
.github/workflows/daily.yml       ежедневное обновление данных
.github/workflows/weekly.yml      еженедельный пост
```

## Если сайт открыт, а data.json недоступен

Страница сама сходит в открытые API напрямую и покажет погоду и курс.
Пустой она не будет.
