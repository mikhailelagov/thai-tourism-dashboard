# Thailand Tourism Demand

## Достоверность данных — 13 октября 2026

Еженедельный пост и утренний отчёт опираются на измеренные и датированные
данные, а не на догадки модели:

| Данные | Источник | Обновление | Сборщик |
|---|---|---|---|
| Прибытия иностранцев по странам | [MOTS](https://www.mots.go.th/news/category/817), XLSX | ежемесячно, ~1 день после конца месяца | `collect_official.py` |
| Загрузка отелей, посещения и доходы по провинциям | [MOTS](https://www.mots.go.th/news/category/820), XLSX | ежемесячно, ~2 недели | `collect_official.py` |
| Брони на 3 месяца, средняя цена номера, загрузка по регионам | [Банк Таиланда, отчёт 875](https://app.bot.or.th/BTWS_STAT/statistics/ReportPage.aspx?language=eng&reportID=875) | ежемесячно | `collect_official.py` → `tourism/indicators.jsonl` |
| Справочные курсы THB к USD, EUR, CNY, INR, KRW, MYR, GBP | ЕЦБ | по рабочим дням | `collect_official.py` |
| Курс рубля к бату | Банк России | по рабочим дням | `collect_official.py` |
| Новости за 10 дней с датой и ссылкой | TAT Newsroom, мэрия Паттайи, DTAM (каннабис), The Pattaya News, The Thaiger, Khaosod English, The Phuket News, Nation Thailand | ежедневно | `collect_news.py` → `tourism/news.json` |
| Погода, 8 дней | Open-Meteo | ежедневно | `build_data.py` |

Сборщики работают только на стандартной библиотеке, представляются честным
User-Agent и не обходят защиту сайтов. Bangkok Post не используется: сайт берёт
плату с ИИ-ботов. Источник, который не ответил, сохраняет прошлые данные, а в
файле появляется запись в `errors`.

**Как пишется пост.** `write_post.py` передаёт модели собранные материалы: цифры
с периодом и источником, новости недели со ссылками, прошлый выпуск. Модель
открывает статьи из списка (web_fetch) и ищет в вебе только недостающее:
не больше 8 поисков и 8 загрузок страниц за запуск. Каждая цифра в посте должна
иметь период и ссылку. Затем второй проход сверяет черновик с материалами и
убирает неподтверждённое. Ссылки на страницы, которых модель не видела,
удаляются кодом. Расход токенов и примерная стоимость пишутся в журнал запуска.

**Оценка 0–100 по направлениям — модель, а не измерение спроса.** Она складывается
из погоды, праздников, цены нефти и курсов валют. Измеренный спрос — это
статистика MOTS и BOT из таблицы выше.

**Если пост не сформировался**, в канал уходит короткая сводка без технических
подробностей. Причина приходит в личный чат (`TELEGRAM_ADMIN_CHAT_ID`), а запуск
на GitHub помечается упавшим, и GitHub присылает письмо.

**Ручной запуск** (Actions → Weekly briefing → Run workflow) по умолчанию
работает как предпросмотр: пост уходит только в `TELEGRAM_ADMIN_CHAT_ID`, а если
этот секрет не задан — выводится в журнал запуска, и в Telegram ничего не уходит.

**API-кредиты.** Подписка Claude Max включает ежемесячные кредиты API: $100 для
Max 5x и $200 для Max 20x. Их нужно один раз привязать к организации Console,
где создан ключ: claude.ai → Settings → Billing → API credits. Один пост стоит
порядка $1–2, точная сумма — в строке `usage:` журнала.

## Облачный сбор и утренняя сводка — 6 сентября 2026

GitHub Actions запускает сбор каждый час примерно на 17-й минуте. Ежедневно
примерно в 08:45 по Бангкоку обновляются открытые показатели и формируется
[утренний отчёт](reports/tourism-latest.md). Оба задания работают на серверах
GitHub при выключенном Mac. Запуски по расписанию могут задерживаться;
в истории хранится реальное время получения, без заполнения пропущенных часов.

Текущий этап камер — проверка доступности выбранных туристических мест.
**Автономный подсчёт Walking Street и Бали Хай пока не подключён**:
публичный stream API Паттайи возвращает `403 BOT_CHALLENGE_FAILED` без
браузерной проверки. Каталог доступен, но его `online` не доказывает работу
видео. Для подсчёта нужен разрешённый поставщиком машинный доступ.
Камеры Bangla Road и Khao San из найденных листингов не работают;
пляжные кадры Windy пока не прошли проверку детализации и фиксированной зоны.

`tourism/cameras.json` задаёт явный список мест и часы наблюдения.
Автомобильные дороги не подбираются по географической близости.
`scripts/collect_tourism.py` сохраняет статусы и метаданные источников в
`footfall.json`; он не скачивает кадры и не обходит браузерную проверку.
Недоступный или непроверенный подсчёт имеет `people: null`, не ноль.
Старые экспериментальные детекции сохранены в истории, но исключены из
сайта и сводки. Отсутствующий обязательный ключ Windy или ошибка источника
оставляет явный пропуск и завершает сбор с ошибкой; история сохраняется.

В утреннем отчёте есть прогноз погодных условий на 72 часа и опубликованные
показатели отелей BOT с периодом и географией. Численный прогноз турпотока
пока не строится: нет проверенного ряда наблюдений. Погода и рыночный
индекс старого сайта не заменяют измерение числа туристов.
`tourism/indicators.jsonl` содержит проверенные месячные точки BOT;
они пока не обновляются автоматически. Скрипт показывает возраст публикации.
Отчёт сохраняется в репозитории; это не отправка личного уведомления.

Проверка: `python3 -m unittest discover -s tests -v`.

Далее описана ранее существовавшая недельная публикация. Её расписание и
получатели не изменены.

Сайт + Telegram-канал со сводкой спроса на туризм по шести направлениям Таиланда.
Всё обновляется автоматически. Ручной календарь событий (`events.json`) необязателен.

```
Ежедневно (cron 08:45 Бангкок)            Понедельник (старт 06:23, пост не раньше 08:00)
  build_data.py, build_history.py           build_data.py → make_chart.py → chart.png
  collect_official.py, collect_news.py      collect_official.py, collect_news.py
       ↓                                         ↓
  data.json, tourism/*.json → сайт          write_post.py → пост (материалы + проверка)
  morning_brief.py → reports/                    ↓
                                            send_telegram.py → канал
```

**Ежедневно** пересобираются данные, сайт всегда свежий, сообщений нет.
**Раз в неделю** выходит развёрнутый пост с графиком.

## Что подтягивается само

| Данные | Источник | Ключ |
|---|---|---|
| Погода, 8 дней, 6 точек | Open-Meteo | не нужен |
| Курсы валют | ЕЦБ, Банк России; ExchangeRate-API как запасной | не нужен |
| Праздники Таиланда | Google Calendar (iCal) | не нужен |
| Праздники стран-доноров | Google Calendar — CN, RU, IN, MY, KR, GB, DE, AU | не нужен |
| Прибытия, загрузка отелей, брони | MOTS, Банк Таиланда | не нужен |
| Новости недели | 8 новостных и официальных лент | не нужен |
| Подробности новостей, маршруты, топливо | web_fetch и веб-поиск модели, с лимитом | нужен API-ключ |

Праздники Таиланда — самый важный календарь, и `date.nager.at` его **не покрывает**
(отдаёт пустой ответ для TH, IN, MY). Поэтому используются публичные iCal-фиды Google.

## Как пишется пост

`write_post.py` даёт Claude Opus 5.5 собранные материалы (см. раздел о
достоверности в начале) и разрешает **дополнительно искать в вебе**, что происходит сейчас: цена авиатоплива, сокращение маршрутов,
статистика приездов, курс бата, события. Модель пишет связный пост, а не
перечисление цифр.

Именно это убирает ручной рыночный контекст. Раньше его надо было обновлять
помесячно — теперь он собирается заново каждую неделю.

Если модель недоступна или ключ не задан, `send_telegram.py` сам соберёт короткую
сводку из `data.json`. Неделя не пройдёт в тишине.

## Что автоматизировать нельзя

- **Загрузка отелей** — открытого API нет ни у кого. Только отчёты ассоциаций.
- **Точная статистика приездов** — публикуется пресс-релизами. Модель найдёт её
  в новостях, но с задержкой и без гарантии свежести.

## Настройка — один раз

### 1. Секреты

**Settings → Secrets and variables → Actions → Secrets:**

| Секрет | Где взять | Обязателен |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` | да |
| `TELEGRAM_CHAT_ID` | см. ниже | да |
| `TELEGRAM_ADMIN_CHAT_ID` | ваш личный id от [@userinfobot](https://t.me/userinfobot) | для уведомлений о сбоях и предпросмотра |
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com) | для развёрнутого поста |

Без `ANTHROPIC_API_KEY` всё работает, но вместо разбора приходит короткая сводка.

### 2. Chat ID

**Себе лично:** написать [@userinfobot](https://t.me/userinfobot), взять `Id`.
Обязательно нажать **Start** у своего бота — иначе он не сможет вам написать.

**В канал:** добавить бота администратором канала с правом публикации, затем взять
id канала — он отрицательный, вида `-1001234567890`. Проще всего переслать любое
сообщение из канала боту [@userinfobot](https://t.me/userinfobot).

### 3. Сайт

**Settings → Pages → Source: Deploy from a branch → `main` / `root`.**

### 4. Проверка

**Actions → Weekly briefing → Run workflow.** По умолчанию включён предпросмотр:
пост придёт только в `TELEGRAM_ADMIN_CHAT_ID`. Снимите галочку, чтобы опубликовать
в канал.

## Расписание

| Задача | Cron | По Бангкоку |
|---|---|---|
| `daily.yml` | `45 1 * * *` | ежедневно 08:45 |
| `weekly.yml` | `23 23 * * 0` | понедельник 06:23, публикация не раньше 08:00 |
| `footfall.yml` | `17 * * * *` | ежечасно (статусы камер) |

GitHub запускает задачи по расписанию с опозданием: в сентябре–октябре 2026
задержка доходила до 6,5 часа. Поэтому «ежечасный» сбор на деле идёт 4–6 раз в
сутки, а еженедельный пост стартует заранее.

## Локальный запуск

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_data.py
.venv/bin/python scripts/make_chart.py
```

Посмотреть, что уйдёт в Telegram, ничего не отправляя:

```bash
DRY_RUN=1 TELEGRAM_BOT_TOKEN=x TELEGRAM_CHAT_ID=x python3 scripts/send_telegram.py
```

Сборщик данных и отправка зависимостей не требуют — только стандартная
библиотека. `matplotlib` нужен для графика, `anthropic` — для поста.

## Как считается оценка условий (не спрос)

```
score = base × (1 − rain_penalty × weather_sensitivity)
        + события + праздник Таиланда (только официальные выходные)
        + праздники за рубежом + поправки на нефть и курсы
```

`base` — заданный вручную уровень направления, `weather_sensitivity` — пляжные
курорты ~0.45, Бангкок 0.15. Это модель условий, а не измерение спроса; оценки
разных направлений между собой не сравниваются. Дни с запретом продажи
алкоголя (буддийские праздники) отмечаются отдельно и баллов не добавляют.
Если в прогнозе нет осадков, день помечается `missing`, а не считается сухим.

## Оформление графика

Малые кратные: по панели на регион, поэтому **цвет не несёт идентичность** —
её несёт заголовок панели. Линия одного акцентного цвета; цветом отмечено
только сегодняшнее значение, и всегда рядом со словесной подписью уровня,
никогда цветом в одиночку. Все цвета данных проверены на контраст ≥ 3:1
к белому фону.

## events.json

Необязательный календарь для того, что не приходит из iCal-фидов: фестивали и
заходы круизных лайнеров.

```json
{"from":"2026-07-30","to":"2026-08-02","scope":"pattaya","boost":18,
 "en":"Fireworks Festival","ru":"Фестиваль фейерверков"}
```

Расписание круизов в Лаем Чабанг известно на год вперёд с точным числом
пассажиров — лучший источник для пиковых дней.
